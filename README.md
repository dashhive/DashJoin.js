# [DashJoin.js](https://github.com/dashhive/DashJoin.js)

Note: it's easiest to test this with two different browsers (not tabs, which
share state).

In EACH Browser:

1. Get some tDASH with the provided Testnet Faucets
   - Unused addresses are at the bottom of the page
2. Set the Cash Drawer parameters for just a few 0.001 denoms
   - 0 everything out (0 priority, 0 wanted)
   - For set 0.001 to Priority 10, and Wanted to 10
3. "Denominate Coins" (below the Cash Drawer)
4. Open the browser console (progress is best seen in the browser)
   - Menu => More Tools => Developer Tools => Console
5. "Run CoinJoin" (below the Cash Drawer)
